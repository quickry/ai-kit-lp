## 7. 切り出し作業ログ（2026-05-05 里見実施）

### 使用ツール
- macOS 26.3 標準 `sips` コマンド
- 作業ディレクトリ: `lp/assets/`

### 作業コマンド一覧

```bash
# Hero画像 1920x1080 (LP Desktop)
sips -Z 1920 hero_main_raw.png --out hero_main_1920x1080.jpg -s format jpeg -s formatOptions 90

# Hero Mobile 750x420
sips -Z 750 hero_main_raw.png --out hero_main_mobile_750x420.jpg -s format jpeg -s formatOptions 88

# OGP 1200x630 (リサイズ→上下クロップ)
sips -Z 1200 hero_main_raw.png --out _ogp_temp.jpg -s format jpeg -s formatOptions 90
sips -c 630 1200 _ogp_temp.jpg --out ogp_1200x630.jpg
rm _ogp_temp.jpg

# Xヘッダー 1500x500 (リサイズ→上下大幅クロップ)
sips -Z 1500 hero_main_raw.png --out _xh_temp.jpg -s format jpeg -s formatOptions 90
sips -c 500 1500 _xh_temp.jpg --out x_header_1500x500.jpg
rm _xh_temp.jpg

# 体験セクション 1600x900
sips -Z 1600 section_experience_raw.png --out section_experience_1600x900.jpg -s format jpeg -s formatOptions 90

# YouTube サムネ 1280x720
sips -Z 1280 section_experience_raw.png --out youtube_thumbnail_1280x720.jpg -s format jpeg -s formatOptions 88
```

### WebP変換について（未実施・佐川睦男引継ぎ）

- macOS 26.3 標準 `sips` の WebP 出力は失敗（コマンドは通るがファイルが正しく生成されないバグ確認）
- `cwebp` バイナリ未導入
- **佐川睦男（LP実装担当）への引継ぎ**: `cwebp -q 85 input.jpg -o output.webp` または `npx @squoosh/cli` または `sharp` で変換を依頼。LP Phase 2 / Phase 3 実装時に picture 要素 srcset へ webp を追加すること

### 注意事項

- 元画像 `hero_main_raw.png` `section_experience_raw.png` は **削除禁止**（履歴保全・原本）
- 切り出し済 jpg ファイルは Phase 2 / Phase 3 実装で参照される。差し替え時は本ファイル §6 履歴に追記必須
