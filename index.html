FAQ

よくある質問

AIを使ったことがなくても大丈夫ですか？
不要です。ただしターミナルで1〜2行のコマンドを打てる必要があります（ステップバイステップの動画付き）。不安な方は Tier 2（リモート構築代行）をおすすめします。
ChatGPTで足りないんでしょうか？
GPTsは「便利なチャット」です。Claude Codeは「ファイル操作・コマンド実行・外部連携を自動で行うAIエージェント基盤」です。本物の業務自動化はClaude Codeでないと実現できません。
Claude Codeの料金は別にかかりますか？
Claude Code の利用料は月額$20〜（約¥3,000〜）です。業務利用なら月$100程度が目安です。本パッケージの代金とは別で発生します。
社内データがAIに学習されないか、心配です。
Claude Codeは学習に使用しないデータポリシーを選択できます。また本パッケージはあなたのPC内でローカルに動作するため、データはあなたの管理下にあります。
ChatGPTやCodexと一緒に使ってもいいですか？
Quickry AI Kit は Claude Code を公式実行環境としています。他AIツール（ChatGPT、Codex、Cursor 等）との併用は技術的に可能なケースもありますが、公式サポートの対象外となります。動作差分・バグ・データ不整合のリスクは利用者にてご判断ください。
Tier 3（3ヶ月伴走）をご契約の方は、併用ワークフローの設計をカスタムで相談可能です。
Notionは持っていないのですが、それでも使えますか？
使えます。Notion連携は任意機能です。使わない場合はMCP連携設定をスキップできます。Google WorkspaceやSlack連携も個別に選べます。
後からTier 2 やTier 3 に変更できますか？
Tier 1購入後にTier 2へアップグレードする場合は差額決済のみ。Tier 2/Tier 3 の解約条件は個別契約書に準じます。
返金はできますか？
デジタルコンテンツの性質上、購入後のご返金には原則対応しておりません。Tier 2・Tier 3 は契約前に十分にご相談のうえ、ご検討ください。Tier 1 は購入前に商品仕様書・FAQ・導入動画のサンプルをご確認いただけます。
購入後、どのくらいで配布物を受け取れますか？

ご決済完了後、当社よりご登録メールアドレス宛にダウンロードリンクをお送りします（原則翌営業日中・営業日カウント基準）。リンク有効期限は30日間です。

営業日とは、当社所定の平日（土日祝日・年末年始を除く）を指します。金曜・祝日前のご決済の場合、翌営業日扱いとなる点ご了承ください。

万一翌営業日を過ぎてもメールが届かない場合は、迷惑メールフォルダをご確認のうえ、support@quickry.jp までお問い合わせください。

Quickry AI Kit は現在「β版（早期提供フェーズ）」として提供しています。配布物（LICENSE・特定商取引法に基づく表記・プライバシーポリシー等）は当社内で精査済みですが、外部弁護士による正式レビューはローンチ後に順次実施・反映してまいります。
